Бизнес-функция: Бронирование отеля

Конкурентный анализ

Рассмотрены сервисы:

* Booking.com
* Ostrovok.ru
* Яндекс Путешествия

Функции конкурентов:

* поиск отелей;
* фильтрация по цене;
* просмотр рейтингов;
* онлайн-бронирование;
* онлайн-оплата;
* уведомление о подтверждении заказа.

Глоссарий

Отель — место размещения туристов.

Номер — помещение для проживания.

Бронирование — резервирование номера на выбранные даты.

Клиент — пользователь сервиса.

Бизнес-цель

Обеспечить возможность быстрого поиска и бронирования отеля через интернет.

Бизнес-процесс

1. Пользователь вводит город и даты поездки.
2. Система показывает доступные отели.
3. Пользователь выбирает отель.
4. Пользователь выбирает номер.
5. Пользователь вводит данные гостя.
6. Пользователь оплачивает заказ.
7. Система подтверждает бронирование.
8. Пользователь получает уведомление на e-mail.

User Story

Как турист,

я хочу забронировать отель онлайн,

чтобы заранее организовать проживание во время поездки.

Ограничения

* наличие свободных номеров;
* наличие доступа к интернету;
* корректные данные пользователя.

DoR

* требования согласованы;
* бизнес-процесс описан;
* определены правила оплаты.

DoD

* поиск работает;
* бронирование создаётся;
* оплата проходит успешно;
* уведомление отправляется пользователю.
